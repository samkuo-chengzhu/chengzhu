旗艦案例 高爾夫產業

高爾夫工坊與教學中心

從分散作業到一套完整的營運系統。 會員、球具 Fitting、工坊派工、庫存、教學與預約， 全部收進同一條資料流——前台成交到後台管理不再需要重複輸入。

看完整案例 →
1,858筆料件即時庫存
29支後端服務上線
7人工坊團隊每天使用

工單走完整的五階段流程，完成動作才能前進；缺料自動進待訂貨清單； 庫存靠掃碼收發盤，每筆都有異動帳。教學端則涵蓋教練、堂數包、 預約核准、完課扣堂與月結拆帳。

Firebase Functions Gen 2 / Firestore / LIFF / Next.js / Rich Menu / 掃碼庫存

連鎖零售

連鎖電器品牌
門市回報自動化

各門市店員每天拍照回傳 LINE，系統自動依店名歸檔到雲端資料夾， 總部每週收到自動產出的統計報表與 email。 從「人工收圖整理」變成「傳完就結束」。

數十間門市同時運作
0分鐘人工整理時間
自動週報 + 月報 + Email

導入前，總部要有人每天從群組把照片一張張抓下來、依門市分類、 月底再彙整成報表。導入後這段流程完全消失，店員的動作也沒有增加—— 他們本來就在傳照片。

FastAPI / 雲端儲存 API / Firebase / 排程報表 / Email 自動寄送

B2B 採購

企業採購查價平台

業務在 LINE 群組說「預算五百到七百、要三百個」， 系統自動搜尋商品、計算階梯報價、回傳商品卡片， 還能直接在 LINE 裡下單、追蹤與處理異常。

2,000+商品即時查價
4 級客戶分級報價
AI自然語言查價下單

定價邏輯是寫死的規則，AI 只負責理解業務講的話，所以不會報錯價。 同義詞會自動修正，業務不用記正確品名。 下單訊息可自動解析成結構化訂單，省掉手抄轉錄。

Gemini / Cloud Functions / Flex Message / 階梯定價引擎 / 匯出報表

連鎖髮廊預約系統

顧客在 LINE 看價目表、點連結預約； 設計師在 LINE 打卡、鎖班、查營收。 休假日曆自動阻擋預約，完工紀錄自動結算日月營收與拆帳。

30 秒完成一筆預約
即時營收儀表板
0額外 App 需下載

導入前月底要花一整天對帳；導入後系統自動算好，老闆只要看數字。 設計師也能自己在 LINE 裡管班表與請假，店長不再是全店的客服。

LIFF / Firestore / Rich Menu 雙層選單 / 行事曆串接 / 拆帳結算

一對一教學

高爾夫教練管理系統

學員用 LIFF 預約課程，教練在 LINE 一鍵核准， 系統自動扣堂數、前一晚推播明日行程、 課程包到期前 30 天自動提醒。

FIFO堂數先到期先扣
雙角色學員端與教練端
自動提醒與到期警告

堂數扣抵用交易確保不會重複扣或漏扣。 學員手上有多個課程包時依到期日先進先出， 避免快到期的放到過期產生爭議。

TypeScript / Cloud Run / Cloud Scheduler / Firestore Transaction / LIFF

社群營運

大型球敘社群報名系統

兩千人規模的 LINE 群組一鍵報名。 額滿自動排候補、有人退出自動遞補並通知， 截止後依同組需求自動分組。

2,000人群組運作
自動候補依序遞補
自動同組需求分組

導入前主辦要在群組裡數「+1」、手記候補順序、私訊通知遞補。 導入後這些全部由系統處理，順位公開透明， 也不會再有「誰先誰後」的爭議。

LINE Messaging API / Flex Message / 候補佇列 / 排程提醒 / 名單匯出

A Note

為什麼這裡沒有客戶名字？

因為我們答應過不寫。這些系統裡有客戶的營收、庫存、會員與定價資料， 有些還是他們的競爭優勢所在。把名字拿出來當行銷素材， 對正在合作的人不公平。

代價是你得多花一點力氣判斷我們的真假。 所以我們把能給的都給了——具體的數字、實際的技術棧， 以及五個可以直接點開操作的 Demo。
